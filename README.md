# HDSci Lab digital cards

Ready-to-upload static website for **MeghaliBanerjee/digital-cards**.

Upload this folder's contents to the repository root on `main`. In **Settings → Pages**, select **Deploy from a branch → main → /(root) → Save**. No build is required.

## Open locally

Extract the entire ZIP first, then open `digital-cards/index.html`. Keep the `assets`, `contacts` and profile folders together. Opening an HTML file from inside a ZIP or moving it away from those folders can make styling and images disappear. All internal page links use explicit relative HTML filenames.
